# Tennessee Eastman Process (TEP) 결함 목록 (자연어 설명)

# 결함 유형 설명:
# - Step: 갑작스럽게 값이 변하는 이상 (예: 한 순간에 값이 확 바뀜)
# - Random Variation: 점진적이고 누적적으로 값이 변하는 이상 (예: 서서히, 불규칙하게 변화)

1. Fault 1: A/C feed ratio, B composition constant (유형: Step)
2. Fault 2: B composition, A/C ratio constant (유형: Step)
3. Fault 3: D feed temperature (유형: Step)
4. Fault 4: Reactor cooling water inlet temperature (유형: Step)
5. Fault 5: Condenser cooling water inlet temperature (유형: Step)
6. Fault 6: A feed loss (유형: Step)
7. Fault 7: C header pressure loss (유형: Step)
8. Fault 8: A, B, C feed composition (유형: Step)
9. Fault 9: D feed temperature (유형: Random Variation)
10. Fault 10: C feed temperature (유형: Random Variation)
11. Fault 11: Reactor cooling water inlet temperature (유형: Random Variation)
12. Fault 12: Condenser cooling water inlet temperature (유형: Random Variation)
