# Tennessee Eastman Process (TEP) 결함 목록 (자연어 설명)

# 결함 유형 설명:
# - Step: 갑작스럽게 값이 변하는 이상 (예: 한 순간에 값이 확 바뀜)
# - Random Walk: 점진적이고 누적적으로 값이 변하는 이상 (예: 서서히, 불규칙하게 변화)

1. Fault 1: 피드 A와 C의 비율에 갑작스러운 이상이 발생하며, B 성분은 일정하게 유지됩니다. (유형: Step)
2. Fault 2: B 성분의 조성에 갑작스러운 이상이 발생하지만, A와 C의 비율은 일정하게 유지됩니다. (유형: Step)
3. Fault 3: D 피드(원료)의 온도에 갑작스러운 이상이 발생합니다. (유형: Step)
4. Fault 4: 반응기 냉각수의 온도에 갑작스러운 이상이 발생합니다. (유형: Step)
5. Fault 5: 응축기 냉각수의 온도에 갑작스러운 이상이 발생합니다. (유형: Step)
6. Fault 6: A 피드(원료)가 갑작스럽게 손실되는 이상이 발생합니다. (유형: Step)
7. Fault 7: C 피드(원료)가 갑작스럽게 손실되는 이상이 발생합니다. (유형: Step)
8. Fault 8: A 및 C 피드의 조성이 갑작스럽게 변화하는 이상이 발생합니다. (유형: Step)
9. Fault 9: D 피드(원료)의 온도가 점진적이고 누적적으로 변화합니다. (유형: Random Walk)
10. Fault 10: C 피드(원료)의 온도가 점진적이고 누적적으로 변화합니다. (유형: Random Walk)
11. Fault 11: 반응기 냉각수의 유량이 점진적으로, 서서히 감소합니다. (유형: Random Walk)
12. Fault 12: 응축기 냉각수의 유량이 점진적으로, 서서히 감소합니다. (유형: Random Walk)
